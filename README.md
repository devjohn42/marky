# Marky

Marky é um aplicativo desktop desenvolvido para ajudar a praticar e explorar o uso do Markdown em um ambiente simples e funcional. Ele foi criado com o objetivo de facilitar o aprendizado e a familiarização com a sintaxe do Markdown, proporcionando uma experiência prática e direta.

Além disso, Marky serve como um projeto de estudo para entender o desenvolvimento de aplicações desktop multiplataforma utilizando Electron e outras tecnologias modernas.

## 🌐 Tecnoligas

- Electron
- Vite
- React-Typescript
- Jotai
- Fs-extra

## ✨ Funcionalidades

### Headings
O plugin Headings permite o uso de títulos markdown que se traduzem em H1 - H6 em HTML.
```
# Hello world
```

### Quotes
The Quote plugin enables the usage of quotes that translate to blockquote in HTML.
```
> This is a quote
```

### Lists
O plug-in Listas permite o uso de listas ordenadas, não ordenadas e de verificação, incluindo vários níveis de aninhamento.
```
 * Item 1
  * Item 2
  * Item 3
    * nested item

  1. Item 1
  2. Item 2
```

### 💽 Atualizações
O Marky ainda não suporta todas as funcionalidades possíveis de um editor Markdown completo. O projeto está em constante evolução, e funcionalidades adicionais serão implementadas no futuro.
